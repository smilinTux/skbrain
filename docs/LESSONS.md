# Lessons

Scrubbed, cross-estate lessons live here, and only here. A lesson that applies to more than one
estate never lands in an estate canon: it is rewritten without any estate detail and added to
this file by pull request to the public repo.

Each entry is one rule, the failure it prevents, and the check that enforces it (or "none yet").
Entries carry no hostname, address, person, client or estate name; `scripts/validate_public.py`
enforces that.
